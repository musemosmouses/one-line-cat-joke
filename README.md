One original single-line joke about a cat: it sits on a laptop mid-interview, the human gets the job anyway — and the cat gets the promotion.

> My cat sat on my laptop during my job interview. I got the job. He's now my manager.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 84 characters, within the 200-character cap.
